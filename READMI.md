# 🚀 StarScream

Минималистичная многопользовательская аркадная игра на **Rust** и **Macroquad** с неблокирующим сетевым клиентом и процедурными эффектами на частицах.

  <img src="assets/demo.gif" alt="Демонстрация геймплея StarScream" width="750"/>
</p>

## ✨ Особенности
* **Интерактивный UI на частицах:** элементы интерфейса, заголовки и кнопки собираются из отдельных частиц при запуске сцены.
* **Световая активация кнопок:** навигация в меню происходит самим кораблём — при налёте на кнопку свет плавно расходится от её центра к краям.
* **Процедурные эффекты:** динамические взрывы с разлётом искр, ударной волной и эффектом рассыпающегося экрана.
* **Неблокирующая сеть:** клиент и сервер работают через неблокирующие сокеты без фризов основного игрового цикла.
* **Инерционная физика полёта:** плавное ускорение, торможение и разворот корабля.

## 🎮 Управление

| Клавиша | Действие |
| :--- | :--- |
| `W` / `↑` | Ускорение вперёд |
| `S` / `↓` | Торможение |
| `A` / `←` | Поворот влево |
| `D` / `→` | Поворот вправо |

## 🛠️ Сборка и запуск

Для сборки требуется только установленный инструментарий [Rust](https://rust-lang.org) (Cargo).

### 1. Запуск сервера
```bash
cd server
cargo run --release
```

### 2. Запуск клиента
```bash
cd starscream_release
cargo run --release
```
